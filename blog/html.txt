파일을 만들고 뒤에 .html 을 붙이면 html 파일이 만들어지며 첫 내용은 ! Enter 를 사용해 첫 토대를 만들수있다.
head 태그 =  웹브라우저에 직접 노출되지않고, meta, title, link, style, script 등의 태그 사용한다.
body 태그 =  웹브라우저에 노출되는내용, 웹브라우저에 표시되는 모든내용은 body 태그영역안에 작성한다.
족보(?) = 부모 형제 자식 같은 관계가 성립된다.
<태그명> = tag, 기능을 사용하기 위한, HTML 문법을 이루는 가장작은 단위
속성 = 기능을 보충하기 위한 역할, 사용해도 되고, 안해도 되고, 여러개를 사용해도되는데 태그없이 사용불가 태그명 옆에 작성
속성값 = 속성="속성값"  ( "큰따옴표 안에 작성") 
문법 = 콘텐츠가 있는 문법(태그로 앞뒤를 감싸야한다.) 과 콘텐츠가 없는 문법으로 나뉨(시작태그만 사용한다.)
주석 = <!--주석내용--> 소스에는 보이되 웹 브라우저에서는 보이지않는다 코드에 대한 메모나 설명을 남길때 사용한다.
style = head 에 들어가며 내부 css 에 해당 작은 범위일수록 힘이 강력하고 같은속성, 같은값일 경우 후순위가로 덮어진다.
h(n) = 제목 부분으로 1~6 까지의 사이즈가 있으면 숫자가 클수록 크기가 작아진다
p = block 요소(공간유무상관없이 줄바꿈)로서 한 문단 을 사용한다 (한줄을 모두사용)
span = inlin 요소(공간이 부족할때만 줄바꿈)로서 한 문장 을 사용한다. (문장의 사용면적만큼만 사용)
br = 텍스트를 줄바꿈 할때 사용한다.
