문법형식 = 선택자 + 선언부
선택자 = CSS 속성을 적용할대상(태그, 요소)을 지정하는영역
선언부 = 선택자로지정된대상(태그, 요소)에적용할CSS 속성과 값을 적는 영역
주석 = /*주석내용*/
내부 스타일 시트 = HTML 문서 내부에 style 태그로 CSS 코드를 작성
외부 스타일 시트 = 별도의 CSS파일을 만들어 HTML 문서와 link 태그로 연결
인라인 스타일 = 모든 태그에서 사용할 수 있는 style 속성을 사용
content = 요소의 내용
padding = 요소의 내부 여백
border = 요소의 테두리
margin = 요소의 외부 여백, 인접한 margin끼리는 큰 값으로 출력
margin-top, margin-left, margin-right, margin-bottom
background-color = 배경색상
width = 가로사이즈 (너비)
height = 세로사이즈 (높이)
box-sizeing =   border-box / content-box 로 나뉨
                border-box : width, height 속성 적용 범위를 border 영역으로 제한
                content-box : width, height 속성 적용 범위를 content 영역으로 제한
display =   박스의 속성을 변경 (기본:block / inline / inline-block / none )
            none            :   표시하지 않음
            block           :   한줄 전체를 차지, 사이즈(width, height) 적용가능, 기본적으로 같이배치X, 여백 적용 가능
            inline          :   컨텐츠 크기만큼만 차지, 사이즈 적용X, 같은줄 옆에 나란히 배치, 여백 적용(좌/우 만 가능)
            inline-block    :   자체적으로는 block 처럼 작동 (사이즈, 여백) 
                                외부적으로는 inline 처럼 작동 (다른요소가 옆에 같은줄에 배치 가능)
☆많이씀☆   flex            :   요소를 플렉스 컨테이너에 넣어 자식요소들을 축 방향, 정렬을 자유롭게 제어 
               flex-direction 속성 : 플렉스 박스 레이아웃의 주축 방향을 지정
                  형식flex-direction:<속성값>;
                     • row : 주축 방향을 왼쪽에서 오른쪽으로 지정 , 기본값
                     • row-reverse : 주축 방향을 오른쪽에서 왼쪽으로 지정
                     • column : 주축 방향을 위쪽에서 아래쪽으로 지정
                     • column-reverse : 주축 방향을 아래쪽에서 위쪽으로 지정
               flex-wrap 속성 : 플렉스 아이템의 자동 줄 바꿈 여부를 지정
                  형식flex-wrap:<속성값>;
                     ▪ nowrap : 플렉스 아이템이 플렉스 컨테이너를벗어나도무시
                     ▪ wrap : 플렉스 아이템이 플렉스 컨테이너를벗어나면줄바꿈
                     ▪ wrap-reverse : 플렉스 아이템이 플렉스 컨테이너를 벗어나면 wrap의 역방향으로줄바꿈
position = 위치 지정 (배치)
            static : 기본 흐름 (기본값)
            relative : 흐름대로 + 위치 조정 가능
                        (위치기준 : 원래 자기가 있어야하는 위치)
                
            absolute : 흐름무시 + 위치 조정 가능
                         (위치기준 : 위치조정이 가능한 부모요소의 시작지점 기준)
                            부모요소 static : 기준점X
                            부모요소 relative : 기준점O
            fixed : 흐름무시 + 절대좌표 위치 지정
            sticky : 흐름대로 + 특정 위치에 가면 fixed 처럼 고정
opacity = 투명도 설정 % (불투명도 0 = 안보임)
cursor = 마우스커서 모양 변경
text-decoration = 내용의 밑줄 취소선 윗줄 등 장식을 작용
margin: 0 auto;  = 블록 요소일때 나 자신을 가운데 정렬한다. (좌우 여백 margin 자동)
                inline 요소 대상 : 작동X
                block 요소 대상 : block 요소 자기자신이 가운데 정렬
text-align: center;  = 내부 컨텐츠 요소가 블록요소일때 가운데 정렬한다.
                inline 요소 대상 : 작동X
                block 요소 대상 : 내부 컨텐츠 요소가 가운데 정렬
block 요소 입장 -> 내가 가운데 정렬 되고 싶다 -> 자기자신 margin: 0 auto;
inline 요소 입장 -> 내가 가운데 정렬 되고 싶다 -> 자기부모 block 요소에 text-align:center;

        }
   </style>

transition = 기존에 보유한 속성값을 변경될 값으로 전환
   transition-property : 전환효과
   transition-duration : 전환까지 걸리는시간
   transition-delay    : 되돌아오는 시간

      transition 속성 위치
      기존    : 마우스 올릴때 O 내릴때 O
      hover  : 마우스 올릴때 O 내릴떄 X
transition-timing-function = 전환효과속도를지정
   형식 transition-timing-function:<속성값>;
      • 속성값
      ▪ linear : 처음 속도와 마지막 속도가 일정
      ▪ ease : 처음에는 속도가 점점 빨라지다가중간부터점점느려짐
      ▪ ease-in : 처음에는 속도가 느리지만 완료될 때까지 점점 빨라짐
      ▪ ease-out : 처음에는 속도가 빠르지만 완료될 때까지 점점 느려짐
      ▪ ease-in-out : 처음에는 속도가 느리지만 점점 빨라지다가 다시 점점느려짐
      • cubic-bezier(p1, p2, p3, p4) : 사용자가 정의한 속도로 진행
