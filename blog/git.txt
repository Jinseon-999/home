git / github

git
    파일의 수정 사항을 시간별로 기록하여 이전 상태로 되돌릴 수 있게 설계된 무료 오픈 소스 분산 버전 관리 시스템

특징과 용도
    분산형 저장소: 모든 개발자가 코드 리포지토리의 전체 기록을 로컬에 저장하는 분산 시스템  
    속도와 효율성: 매우 빠른 속도를 제공하며, 대규모 프로젝트부터 소규모 프로젝트까지 효율적으로 관리할 수 있다
    협업 지원: 코드 변경 이력을 관리하여 여러 사람과 협업할 때 누가 무엇을 수정했는지 명확히 알 수 있게 돕는다

github
    git으로 관리하는 프로젝트를 인터넷에 저장하고 공유할 수 있는 플랫폼
    [코드저장, 프로젝트공유, 협업, 백업 등 개발자가만든 소스코드를 온라인에 보관하고 다른사람과 함께 할수있는 공간]


주명령어

cd (이동) 
ls (목록)
git init 
git add 파일명
git add .
git commit -m '작업내용'
git remote origin "깃허브 주소'
git clone "깃허브 주소'
git push origin main 
git pull origin main 
git branch (브랜치목록)
git branch '파일명' (브랜치추가)
git checkout -b '브랜치명' (브랜치추가하면서 해당 브랜치로 이동)
git checkout '브랜치명' (해당 브랜치로 브랜치 이동)
git branch -d '브랜치명' (해당 브랜치 삭제)
git merge '브랜치명' (현재 브랜치에 병합할 브랜치)
