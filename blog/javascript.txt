내부 / 외부 스타일
    내부 : html 파일에 <body> 하단부분에 <script>를 열어 코드를 작성
    외부 : js 파일을 따로 작성하여 <script src="./외부js파일.js"></script> 외부링크를 <head> 에 작성

변수선언
변수 타입
var : 거의 안씀
let const : 주로 씀

변수 let    : 임시저장해서 쓰는개념 / 공간 / 할당이나저장된 값 바꾸기가능 
상수 const  : 한번 할당/저장 하면 값이 바뀌지 않는다

변수명 숫자시작불가, $ _ 이외에 특수문자 불가, 띄어쓰기 불가, 예약어(키워드) 불가
