배열 = 변수값들을 모아서 관리한다  /  배열변수[인덱스]; /  for문이랑 매우 친함
인덱스 (index) = 몇번째 값을 가져오는 역할 / 대부분 0부터 시작이며 간혹 1부터 시작 / 확인해보는 습관을 들여놓는게 좋다
배열의 값에 접근 - for 문  / for in (인덱스 값) / for of (배열에 있는 값) / forEach (배열구조에서 제공하는 함수)

    let scores = [11, 22, 33, 44, 55]; // 5명의 점수

    1) for문 + index 접근

    for(let i=0; i<scores.length; i++){ // i<5; 0 1 2 3 4
        console.log( scores[i] )}

    2) for in       -> index 값 획득

    for(let i in scores){
        console.log(i + " 인덱스 위치의 값 : " + scores[i]);
    }

    3) for of       -> 배열에 있는 값 획득

    for(let v of scores){
        console.log(v);
    }

    4) 배열 구조에서 제공하는 함수 forEach

    scores.forEach( (value, index)=>{
        console.log(index + " : " + value);
    } )
