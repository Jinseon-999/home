도메인과 DNS란 무엇인가?

도메인 :

사람이 기억하기 쉽도록 영문, 한글 같은 문자로 만든 인터넷 주소 
( [예시] www.naver.com = .com은 최상위 도메인(TLD), naver는 등록된 고유 이름 )

DNS : 

DNS(Domain Name System)는 도메인을 IP 주소로 변환해주는 시스템

도메인과 DNS 의 관계 :

도메인은 사람이 외우는 주소이며, 
DNS(Domain Name System)는 그 주소를 컴퓨터가 찾아가는 실제 IP 주소로 바꿔주는 인터넷의 전화번호부 역할
도메인 네임 시스템(DNS)은 도메인 네임을 IP 주소로 변환하고 라우팅 정보를 제공하는 분산형 데이터베이스 시스템입니다.

([예시] 도메인주소    ===>     DNS     ===>     IP)
                    요청     변환     제공   

                    
+DNS 서버가 고장나면 웹사이트 접속은 어떻게 될까?

인터넷 연결은 유지가 되어도 도메인 이름을  IP 주소로 변환 할수없기때문에 접속할 수 없다.
    " 서버를 찾을수없음 " 과 같은 오류 메시지가 나온다.
